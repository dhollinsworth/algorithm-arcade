Teacher launch guide · a 45–55 minute lesson

Model one sushi plate together (5 min). Pairs play Sushi shift (10 min), Vault search (8 min), Bubble cargo (12 min), then Algorithm detective independently (8 min). Use the remaining time to discuss mistakes.

Pair roles: one student predicts aloud; the other operates the controls. Swap roles after every round. Ask “Which variable changes, and why?” before accepting a click.

Differentiate: Learn offers smaller datasets and prompts. Practise adds data. Challenge includes negatives, duplicate search values and missing targets. All modes use the same underlying concepts.

Exit ticket: Explain the difference between counting and totalling; trace one bubble-sort pass; explain how you know a linear-search target is absent. A completion badge means a game was finished, not that independent mastery has been assessed.

Sharing: this downloadable page runs offline in a browser. Upload the HTML to Classroom and tell students to download it, then open it in Chrome or Edge. Progress is stored only in that browser when storage is available; no names or results are sent to the teacher.
