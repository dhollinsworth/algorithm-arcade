2. I do — Watch the example 10 minutes

CSS rules have a selector, a property and a value.

Worked example
h1 {
  color: purple;
}
Read it: “Select every h1 heading and make its text purple.”
Remember the : after the property and ; after the value.

4. You do — Creature card challenge 20 minutes

Make your own styled creature card. You can use the existing code: you do not need to start from scratch.

Everyone: change the heading colour and background. Core: change the border, font size and alignment. Challenge: add a new property and explain why your choices make the page easy to read.

Support — copy and adapt

Use color: red; for text, background-color: pink; for the background, border: 3px solid green; for a border. Change just one value at a time.

Stretch — debugging
